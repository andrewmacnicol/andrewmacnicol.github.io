weekahead-slides

A personal automation for one teacher's own class materials.

Privacy policyTerms of service

weekahead-slides is a private, single-user tool. Each afternoon it updates a small set of Google Slides presentations that its owner created, so they show the current week's class plan. It is not a public service: nobody else can sign up for it or use it.

Privacy policy

What it accesses. With the owner's permission, the app uses the Google Slides API to read and edit specific presentations in the owner's own Google account. It does not access Gmail, Contacts, Calendar, or any other Google data.

What it stores. The app keeps its Google sign-in token on the owner's private home server so it can run on a schedule. It does not copy or keep the contents of any presentation after an update.

Sharing. No data is sold, shared with third parties, or used for advertising or analytics. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be removed at any time from Google Account → Third-party apps & services.
